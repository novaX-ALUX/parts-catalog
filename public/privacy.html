Privacy Policy — novaX ALUX mail assistant

Last updated: 2026-10-10

What this app is

This is a private tool used only by its owner (the Google account that authorizes it). It reads the owner's own Gmail messages to summarize them and to prepare draft replies inside the owner's Gmail drafts folder. It is not offered to the public.

Data accessed

With the owner's permission, the app reads message headers, bodies and attachments of the owner's mailbox, and creates drafts or labels in that mailbox. Messages are sent only when the owner explicitly approves each one.

Storage and sharing

Data is processed on the owner's own computer. It is not sold, not used for advertising, and not shared with any third party. Access tokens are stored only on the owner's computer and can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
